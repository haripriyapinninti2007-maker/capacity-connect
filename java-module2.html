📦 Module 2 — Variables & Data Types

In this module, we will learn about variables and different data types used in Java programming.

What is a Variable?

A variable is a named memory location used to store data. The value of a variable can be changed during program execution.

Example

int age = 20;
double price = 99.50;
char grade = 'A';
String name = "Rahul";

Java Data Types

  • int — stores integer numbers
  • float — stores decimal numbers
  • double — stores larger decimal values
  • char — stores a single character
  • boolean — stores true or false
  • String — stores text

Important Points

  • Every variable has a data type.
  • Variable names should be meaningful.
  • Java is a strongly typed language.
