What is Java?

Java is a popular programming language used to develop applications, websites, mobile applications and software systems.

Features of Java

  • Simple and easy to learn
  • Object-Oriented
  • Platform Independent
  • Secure
  • Portable

First Java Program

Example of a simple Java program:

public class Hello {

    public static void main(String[] args) {
        System.out.println("Hello World");
    }

}
