📘 What is a String?

A String is a sequence of characters.

String name = "Java";
System.out.println(name);

🔧 Common String Methods

  • toUpperCase()
  • toLowerCase()

String s = "Java";

System.out.println(s.length());
System.out.println(s.toUpperCase());
System.out.println(s.toLowerCase());
