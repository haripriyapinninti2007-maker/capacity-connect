Module 8 — Exception Handling

📘 What is an Exception?

An exception is an unwanted event that occurs during program execution and can interrupt the normal flow of the program.

🛡️ try-catch

The try block contains risky code and catch handles the exception.

try {
    int a = 10 / 0;
}
catch(ArithmeticException e) {
    System.out.println("Cannot divide by zero");
}

🔧 finally

The finally block is used for code that should execute after try-catch.

try {
    System.out.println("Try block");
}
catch(Exception e) {
    System.out.println("Exception");
}
finally {
    System.out.println("Finally block");
}
